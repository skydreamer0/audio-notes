# 雲端同意、重試與音檔生命週期契約（Issue #2／#3）

**狀態：規格候選，未實作或驗收。** 基線：程式 main `48a0bcad14373728e24955264bc5ceddd4981622`；已推送的 #2 文件 `e5e6abf085ca544f27613a1c4a203b8189c66af6`；#3 的 Issue 原文及 2026-11-01 獨立審查。這份文件只定義可決定的安全行為，不取代其餘原始驗收。先前兩份本機未推送 SPEC 不在本執行環境，內容未知；沒有讀取、覆寫或宣稱同步它們。英文對照見 [English](consent-lifecycle-contract.en.md)。

## C1. 同意身分與預設

首次外送前，說明音訊經本機 bridge 傳至非官方 ChatGPT 轉錄端點、用途及傳輸方式；取消無法撤回已送出資料。顯示「同意並送出」「取消」以及預設未勾選的「記住我的選擇」。拒絕／關閉／取消不得送出。保存失敗時不聲稱已記住；本次僅在明確同意後可送，下一次仍詢問。不得保存音訊、逐字稿、key 或 token 作為同意紀錄。

可重用的同意必須綁定版本化 tuple：已驗證的實際接收者身分、用途、傳輸方式、同意文字版本；另記同意時間。識別必須由能驗證**本次實際轉送路徑**的可信機制提供，並在每次送出前驗證；僅本機 URL、health 成功、自稱字串或程序存活不足以證明。現行 bridge 未提供此機制：實作時視為識別未知、記住選項不可生效並說明原因，每次送出都要求新同意。不得憑硬編碼的預期上游冒充已驗證。未來若有可信機制，須另有來源、驗證與失效證據及審查；不能由此規格假定存在。

缺少、損壞、不可讀、無法驗證或 tuple 任一欄位／文字版本變更時，同意失效，送出前重新詢問。設定頁提供「雲端辨識」狀態、接收者／用途／傳輸說明、有效／未知原因及「撤回同意」；撤回立即取消可重用授權，下一次須新同意。撤回不撤回已送資料，也不假稱中止服務端處理。保存／撤回失敗須顯示失敗；即使撤回持久化失敗，該程序仍 fail closed 並禁止沿用舊紀錄。重新啟動讀到失敗的舊紀錄時不能把撤回聲稱已持久成功；需給使用者可見修復路徑，無法確定狀態則每次詢問。

## C2. 重試是獨立決定

不自動重送。使用者明確選「重試」後，若前次可能已送出但結果未知（例如送出後斷線、逾時、取消或未知服務錯誤），獨立提示可能重複處理及可能費用，要求明確「仍要重試」；取消、關閉或拒絕都不送。此提示不等於資料去向同意；先完成必要的風險確認，再依 C1 取得或驗證同意，兩個守衛都通過才送。已知請求未送出的失敗不必顯示未知結果警告，但仍需 C1。記住資料去向同意不得跳過風險確認。

## C3. 取消、所有權與並發

同一 app 程序最多一項錄音／匯入／轉錄工作。取消立即更新畫面、發出取消請求、使該工作 generation 失效；遲到成功或失敗不得更新畫面、歷史、剪貼簿或新工作的狀態。直到舊請求及其所有 stream 確實結束並釋放，禁止新錄音、匯入、送出與重試；UI 顯示「正在結束上一項工作」，不假稱已清除。若一直不釋放，保留受保護檔案，提供關閉程式指引；正常結束最多等 5 秒，超時可退出但記為未清理，不能強殺其他程序或保證服務端停止。

程式擁有的錄音與匯入快照位於專用工作目錄；使用者原始匯入檔永不刪除或覆寫。每次啟動使用不可重用的隨機工作目錄 ID，受限於本使用者 ACL，禁止連結／junction／reparse point 跳出根目錄。所有活躍 owner 在存取其目錄前取得且持有跨程序、跨 Windows session 的獨占 OS 鎖；清理者先對同一穩定鎖取得非阻塞獨占鎖，失敗或無法驗證時跳過，不讀寫刪除。鎖名稱不能重用；清理持鎖至完成，鎖物件本身不可在競爭中刪除重建。若平台不能提供這種鎖及安全路徑驗證，停用自動清理而非猜測是否閒置。這是實作合約，尚非已實作的 Windows 機制。

僅清理可證明屬本程式、無活躍 owner、超過 24 小時的殘留；時間不可信／時鐘倒退／擁有權或路徑不明則跳過。成功、放棄或取消後，僅在全部 stream 釋放並取得鎖時清理。刪除失敗不得顯示成功，保留至未來符合條件的啟動重試；未滿 24 小時可能更晚才清理。診斷只記安全錯誤類別、時間及匿名工作識別，不記檔案路徑、內容或秘密。

## C4. 匯入檔一致性

只接受可驗證本機一般檔案及具備所需鎖語意的儲存；網路檔案、reparse point 或無法證明語意的檔案一律停止，不宣稱抵抗具有系統層寫入能力的惡意程式。每次送出前使用只允許讀取分享、拒絕其他寫入／刪除的 Windows 檔案控制代碼固定來源，建立程式擁有的快照；驗證該快照格式、時長、大小及 SHA-256，再顯示同意。直到同意完成及送出開始，維持來源控制代碼，並核對來源檔案識別、大小與雜湊仍與快照相符。若無法取得或維持保護、來源變動、讀取失敗或比對不符，關閉本次流程，不送出；重新選取、建立並驗證快照，並重新取得本次資料去向同意。快照完成寫入後，以拒絕其他寫入／刪除分享的唯讀控制代碼開啟快照；以這個**同一控制代碼**完成格式、大小、時長與雜湊驗證，持續持有跨過同意視窗，送出前再檢查檔案識別、大小與雜湊；不符、保護失效或無法驗證均零傳送。送出時將同一控制代碼的讀取位置重設至起點，並由此控制代碼串流至請求完成與釋放，不以路徑重新開啟。只傳送該已驗證快照，不再從來源路徑重新開檔。快照也受 C3 鎖與清理規則保護；不刪除使用者原檔。重試須重新驗證音訊可用；若來源或快照已變更／不可驗證，當作新資料重新確認，不沿用舊音檔同意。

## C5. 可重現驗收（均待執行）

- 表格測試：首次、未記住、明確記住、重啟、撤回、儲存／撤回失敗、設定損壞、tuple 各欄／文字版本變更、識別未知；記錄同意窗與傳送次數。現行 bridge 每次均詢問；只用可驗證的假測試供應者測試可記住分支。
- 前次未送出與結果未知各測；未知時有風險確認，記住同意也不能跳過；拒絕任一守衛均零送出；連點不重複。mock 不代表真服務成功。
- 跨程序及兩個 Windows session：活鎖、鎖競爭、異常退出、時間回撥、未滿／超過 24 小時、reparse point、刪除與鎖取得失敗；活躍資料不被刪，失敗可見且無敏感日誌。鎖語意無法證明即 BLOCKED，非 PASS。
- 控制請求永不釋放、遲到成功／失敗、取消、關閉逾時；檢查新工作被阻擋、舊結果被忽略與檔案保護。模擬同意前改寫、替換、刪除或無法鎖來源，均零送出；原始檔 bytes 不變。模擬同意期間及送出前嘗試透過另一控制代碼改寫、刪除或替換快照，或驗證失配／保護失效時均零傳送；驗證正常情況同一受保護控制代碼的送出 bytes 與受驗快照完全一致。
- Windows 100%／150%、深淺色、鍵盤焦點、螢幕助讀名稱、最小及一般視窗：從主視窗以滑鼠或鍵盤開啟「設定」→「雲端辨識與同意」，檢查狀態、撤回按鈕及結果；每個控制項須有可辨識的 accessible name、可用 Tab／Shift+Tab 到達、Enter／Space 操作並有可見焦點。撤回失敗時保留失敗訊息，並以螢幕助讀可接收的狀態／警示宣告；記錄解析度與結果；對比依可量測的 WCAG 2.2 AA（一般文字 4.5:1、大文字 3:1、必要控制項 3:1）並記例外。中英文 README 須說明記住／撤回／失效／未知與獨立風險提示；不覆寫使用者逐字稿。
