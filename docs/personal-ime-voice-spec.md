# 個人注音與語音輸入：實作規格 v0.1

狀態：規劃，尚未實作或驗收。此文件建立在 audio-notes main 的現行設計與唯讀檢查所得資訊之上；本文件不是可執行產品。

## 目標

建立使用者自己的 Windows 繁體中文注音輸入法，結合語音輸入、個人詞庫與可恢復的草稿，能用於 Codex 及其他常見 Windows 應用。中文候選字及注音鍵盤體驗應能以實際使用比較自然輸入法，但不得宣稱已達同等品質。

## 已知基線與證據邊界

- audio-notes 現有 Windows 介面以固定版本的兩個 MIT 上游整合；支援錄音、匯入、預覽、複製及歷史。README 聲明雲端轉錄、本機 loopback 限制，無自動注入。其實際建置和執行驗證應依 Issue #3 和實際版本證據核對，不以 README 或舊聊天代替最新驗收。
- 先前已規劃 Mac mini 本機 ASR 服務與 OpenAI 相容介面；目前沒有本 SPEC 可驗證的服務部署、網路、授權或真實轉錄證據。不可假設服務已啟用。
- REA 對現有輸入法的靜態檢查辨識到 32/64 位元元件、服務程式和資料檔，以及鍵盤、視窗及 RPC 相關匯入。這不揭示完整功能、詞庫、組字及排序演算法，也不證明執行時呼叫或可重建原始程式。
- 使用者回報 Codex 視窗閃爍或重新載入後，尚未送出的整段文字消失。根因未確認；不得將舊版更新程式故障或任何靜態結果說成根因。
- 既有專有程式、詞庫和資源不因本規格取得再利用授權；新實作應以自建、可合法使用或另獲授權的來源為基礎，保留來源與授權記錄。

## 交付範圍

### A. 全系統注音輸入法

1. 提供 Windows TSF 文字服務，處理啟用／停用、焦點變動、組字、上屏、取消、Backspace、候選字選擇及中文／英文切換。支援標準注音鍵盤、常用標點和候選字翻頁。鍵位、候選數與快捷鍵可設定；預設鍵位與選擇方式須提供可讀清單。
2. 32/64 位元目標程式都須列入相容性驗收；明示實際提供的架構和不支援情境。隔離安裝、卸載及回復方式，測試期間不移除或覆寫現有輸入法，不改預設輸入法。
3. 獨立管理候選排序與詞庫：支援注音到候選、使用者自訂詞彙、人工修正或刪除和可關閉的排序調整。詞庫來源、版權、格式、更新及遷移有記錄。不可把匯入宣告、靜態字串或空清單視為完成詞庫或品質。
4. 高頻輸入路徑維持可用：後端卡住／失聯時有明確狀態及可取消操作；不阻塞宿主 UI，不任意丟棄已確認的文字；候選字視窗在縮放、多螢幕、焦點變更與常見無障礙操作中驗證。
5. 不讀取、儲存或記錄密碼欄、其他應用的完整內容或鍵盤輸入歷史。處理受保護輸入範圍、權限及不支援狀態的策略需驗證；不能保證每種應用都允許完整識別，未知時採保守行為。

### B. 語音輸入

1. 沿用現有 audio-notes 可重用介面與來源授權；先核現有 Issue #2、#3 的未完成項，保持目前 loopback 安全邊界，不因整合而弱化。將辨識後端定義為可替換 adapter，不假設既有非官方雲端服務或 Mac mini 已可用。
2. 支援使用者主動開始／停止錄音、取消、辨識進度、錯誤與結果預覽。麥克風權限不足、無裝置、靜音、網路失敗或模型不可用時保留既有草稿並顯示可行的下一步。
3. 語音結果可編輯後明確確認插入；焦點或目標變動時要求再次選定，不注入錯誤視窗、不自動送出訊息。插入失敗須保留結果供複製；不可宣稱跨所有應用保證成功。
4. 提供個人詞彙與可選修正紀錄，原始辨識及編輯後文字分開；這不等於自動模型訓練。錄音及逐字稿留存預設關閉，提供刪除與可理解的儲存說明；雲端或跨裝置傳送須在使用者明確選擇後揭露接收者與資料流。
5. Mac mini ASR 視為可選未驗證後端：先確認實際部署、版本、認證、介面、網路與端到端表現，再設計安全連線。127.0.0.1 僅指各自裝置，不能直接視為跨機連線；保持既有 audio-notes loopback 約束，跨機須另有經評估的安全轉接方案。

### C. 草稿保護與 Codex

1. 提供使用者自己的可編輯草稿區與自動保存、重開復原、明確刪除與可見保存狀態。保存失敗可見且不得覆蓋唯一可恢復副本；測試重啟與中斷。草稿存放本機並提供保留及清除控制。
2. 在獨立草稿區完成輸入後，由使用者確認複製或插入目標。焦點不明、目標關閉或插入失敗時保留草稿。不得自動送出 Codex 訊息。
3. 獨立輸入法不能承諾恢復只存在於其他程式輸入框、且從未進入本工具的文字；Codex 輸入框重載問題與此方案分開調查。要解決原位草稿需 Codex 本身的狀態保存或另經評估的整合。
4. 可選診斷只記版本、事件種類、時間與失敗碼；不收集實際輸入文字、音訊、帳號或機密。

## 階段

- P0：固定既有來源及 Windows 基線，盤點現有工程、issue、授權與相容性；建立草稿與語音流程可操作原型，保留未驗項目。P0 不取代完整輸入法。
- P1：獨立草稿保護＋音訊錄製／可替換 ASR adapter；先使用可控模擬後端，經明確同意才做真人錄音與資料傳輸測試。
- P2：TSF 注音組字、候選、詞庫與設定；32/64 位元支援和安裝回復驗收。
- P3：與語音、草稿、現有 audio-notes 整合；同版 Windows 真機測試，與自然輸入法就常用情境比較。依結果修正，未達驗收不得宣稱可取代。
